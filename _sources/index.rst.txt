Tortreinador documentation
==========================

Build your training step. Keep control of your PyTorch model.

Tortreinador connects a model, an optimizer and your calculation code to an
epoch loop with metrics, events, logging and checkpoints. Start with a complete
CPU example, then adapt the same workflow to your own data and models.

Choose a starting point
-----------------------

* **New to the package?** Follow :doc:`installation` and :doc:`quickstart`.
* **Bringing an existing model?** Read :doc:`training` for the calculation contract.
* **Running experiments?** Use :doc:`metrics`, :doc:`events` and :doc:`hpo`.
* **Checking a result?** Read :doc:`compatibility` for tested environments and known issues.

The guides describe the local 0.2.5 source snapshot audited on November 12, 2026.
Examples use explicit metric definitions and separate training and validation
metrics. See :doc:`known-issues` before enabling resume or built-in schedulers.
