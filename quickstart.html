Quickstart: train a regression model#

This tutorial fits y = 2x + 1 on synthetic data. It runs on CPU, downloads no data and demonstrates the complete training contract.

1. Prepare independent splits#

Create input and target tensors with shape (samples, features). Shuffle the indices once, reserve validation samples and wrap both splits in dataloaders. Use num_workers=0 for a portable first run.

2. Define the calculation#

Subclass TorchTrainer and implement calculate(x, y, mode). Compute the loss and return self._standard_return(...). The trainer performs zero_grad(), backward() and step(); do not repeat them here.

3. Register metrics#

Use separate train_loss and val_loss definitions. Mode 1 runs during training; mode 2 runs during validation. Exactly one training metric is the criterion used for backpropagation. A validation loss can also drive best-model detection. This separation keeps validation statistics independent of training.

4. Run the complete example#

"""Run from the repository root: python docs/examples/quickstart.py."""
import torch
from torch import nn
from tortreinador.train import TorchTrainer, config_generator
from tortreinador.utils.preprocessing import get_dataloader
from tortreinador.utils.Recorder import MetricDefine, MetricManager


class RegressionTrainer(TorchTrainer):
    def calculate(self, x, y, mode=1):
        prediction = self.model(x)
        loss = self.criterion(prediction, y)
        return self._standard_return(mode=mode, update_values=[loss])


def main():
    torch.manual_seed(42)
    x = torch.linspace(-1, 1, 160).reshape(-1, 1)
    y = 2 * x + 1
    indices = torch.randperm(len(x))
    train_idx, val_idx = indices[:128], indices[128:]
    train = get_dataloader(x[train_idx], y[train_idx], 16, True, num_workers=0)
    val = get_dataloader(x[val_idx], y[val_idx], 16, False, num_workers=0)
    model = nn.Linear(1, 1)
    metrics = MetricManager([
        MetricDefine('train_loss', metric_mode=1, use_as_criterion=True),
        MetricDefine('val_loss', metric_mode=2, use_as_valloss=True, use_for_log=True),
    ])
    trainer = RegressionTrainer(is_gpu=False, epoch=20, model=model,
        optimizer=torch.optim.SGD(model.parameters(), lr=0.1),
        criterion=nn.MSELoss(), metric_manager=metrics)
    config = config_generator(best_loss=float('inf'))
    history = trainer.fit(train, val, tqdm_disable=True, **config)
    validation_losses = history[0].recorder_for_epoch['val_loss'].val
    print(f'Final validation MSE: {validation_losses[-1].item():.6f}')
    model.eval()
    with torch.no_grad():
        prediction = model(torch.tensor([[0.5]]))
    print(f'Prediction for x=0.5: {prediction.item():.4f}')
    return validation_losses, prediction


if __name__ == '__main__':
    main()

Save this script or download quickstart.py. After installing the package, run:

python docs/examples/quickstart.py

The validation MSE should approach zero and the prediction should approach 2.0. Small floating-point differences are normal. No checkpoint is written because this example does not configure a save path or autosave interval.

5. Inspect the result#

In recorder mode, fit returns a list of event listeners. For a fresh trainer, history[0].recorder_for_epoch maps metric names to RecorderForEpoch objects. Their .val tensors contain values captured on validation epochs. With validation_cycle=2, history therefore has one entry every two epochs.
